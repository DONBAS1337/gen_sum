# Статус согласованного плана

Текущий конечный объём реализован. Это не обещание симулировать бесконечное множество любых поступков или точно воспроизвести все сценарии доноров.

| Направление | Реализовано |
| --- | --- |
| Проверяемые поступки | Интерпретатор намерения, действия с объектами, предметами, проектами, риском и лагерными делами; требования и последствия проверяет движок |
| Долгая память | Свидетели, факты и убеждения, экземпляры вещей, обещания, сроки, встречи, последствия лжи и личные воспоминания |
| Различия характеров | 11 профилей приоритетов и конфликтов, разные реакции, стресс и восстановление, собственные инициативы и частная память |
| Отношения через опыт | Реальное совместное участие, подтверждённый роман отдельно от дружбы, согласие на жест, занятость и отказ |
| Каталог ресурсов | Все 1362 файловые CG учтены и получили визуальную классификацию либо явное исключение; BG/спрайты проиндексированы; финальная проверка CG по сцене обязательна |
| Режиссура | Фоны по месту/времени, до четырёх спрайтов, эмоции, позы, дистанция, праздничные костюмы, музыка и окружение |
| События с продолжением | Концерт, прогулка и эфир: варианты плана, реальные этапы, автономные вклады NPC, результат и следующий разговор; разбор влияет на новое событие |
| Темп | 3/5/8 минут на реплику, частота инициативных визитов; чтение и ожидание ИИ не расходуют игровое время |
| Устойчивость | Снимки слотов, архив будущего, отмена незафиксированного хода, защита от устаревшего запроса, атомарное сохранение с повторами при блокировке Windows |
| Управление сменами | Удаление в корзину, восстановление, подтверждаемое окончательное удаление; защита от возобновления удалённой смены старым слотом |
| Длинная смена | Автоматический прогон 120 дней и 13631 действия завершён; проверены сохранения, исторические снимки и отказы до фиксации |

Проверки: 390 тестов, Ren’Py 7.4.11, Python 2; отдельная цепочка из пяти сцен с живым ИИ. Подробные границы и способ проверки: [FEATURES_RU.md](FEATURES_RU.md).

За пределами этого объёма: универсальная физика любого действия, безошибочный ИИ, ручная художественная редактура каждой сгенерированной сцены, автоматическая сборка всех сложных составных CG доноров, генерация спрайтов и дальнейшая работа с ComfyUI. Полное ручное прохождение игроком не заявляется как выполненная проверка.
