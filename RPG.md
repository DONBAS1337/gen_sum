# Generative Summer RPG — первая экспериментальная сборка

Основа: `gen-7dl-vanilla`. Новая ветка: `feature/camp-sandbox-rpg`.

## Что реализовано

- Отдельный режим «Открытый мир · RPG» в главном меню, при этом старые истории и их система глав не изменены.
- Создание героя: имя, возраст (14–80), обращение, предыстория, длина смены (1–120 игровых дней), мир vanilla или 7ДЛ-Мику (если установлен).
- Схематичная интерактивная карта 12 локаций; свободные перемещения сами по себе не вызывают запросы к нейросети.
- 11 персонажей с расписанием для четырёх периодов суток, включая небольшие вариации по дням.
- Беседы, отдых, помощь лагерю, исследование и тренировки. Энергия, навыки, доброта, любознательность; время течёт от активностей, не от открытия карты.
- У каждого героя отношение 0–100. На 10/25/45/70 очков доступны сюжетные этапы рута с тремя вариантами реакции. События и выбранные ответы записываются в журнал.
- Три задания: познакомиться с персонажами, помочь лагерю, посетить разные места; за выполнение начисляются очки.
- Отдельные сохранения RPG в `saves/generative_summer/_rpg/*.json` с резервной копией предыдущего состояния. При сбое основного JSON доступна `.bak`.
- Особая AI-сцена по кнопке рядом с персонажем: свободный текст поступка, имя героя, текущее место, время, отношения, события и последние сцены передаются LLM. Сгенерированное сохраняется в RPG-дневнике и не перезаписывает характеристики.
- Запрос отсутствующего фона локации или прозрачного PNG-спрайта по кнопке. Результат кешируется в сохранениях и показывается при следующих посещениях. Если сеть недоступна, игра продолжает работать с существующим изображением либо заглушкой.

## Установка

1. Нужна установленная исходная Workshop-версия «Генеративного лета», Steam Workshop ID `3800447567`. Работает в существующей папке мода `mods/generative_summer`, а не как отдельный пустой мод.
2. Скачайте ZIP **этой ветки**, распакуйте и закройте Everlasting Summer.
3. Запустите из папки проекта:
   ```powershell
   .\install.ps1 -ModDir "D:\SteamLibrary\steamapps\workshop\content\331470\3800447567\mods\generative_summer"
   ```
4. Скрипт создаст `community_fix_backup_...`, установит нужные файлы и удалит устаревшие `.pyo/.rpyc`.
5. Запустите игру → «Генеративное лето» → «Открытый мир · RPG».

Остаются обязательными Windows, системный Python 3 и `curl.exe` для нейрогенерации, как в исходной ветке. **Локальный RPG-движок обходится без этих сетевых запросов.**

## Что пока экспериментальное

- Это не полная нелинейная RPG: этапы рутов пока короткие системные события, а полноценные уникальные сюжетные ветки и взаимосвязанные квесты — следующий этап.
- Карта **схематичная**, не нарисованный отдельный фон с точной географией лагеря; кнопки задают переходы.
- Расписания фиксированные с небольшими вариациями, нет продвинутого поведения NPC, инвентаря, экономики и событий по таймеру.
- Для AI-сцен при выбранном профиле 7ДЛ загружаются релевантные фрагменты текстового индекса 7ДЛ; полноценная система всех рутов 7ДЛ пока не перенесена.
- Прозрачные спрайты генерируются best-effort. При неподдерживаемом параметре изображения либо отсутствии alpha-канала показывается ошибка, старый спрайт остаётся. Встроенная генерация фоновых изображений в классическом режиме не изменяет своё поведение.
- Автоматические тесты проверяют Python-движок и PNG-хранилище. **Реальный smoke-test рендеринга экранов в установленном Ren'Py/Everlasting Summer обязателен**: CI не запускает саму игру.
- Обычные старые истории и новые RPG-смены хранятся независимо. Данные RPG не должны редактироваться вручную во время запуска игры.

## Архитектура

```
generative_summer.rpy  ->  gs_rpg_main (gs_rpg.rpy)
                                  |
                                  v
                           gs_rpg.py (offline)
                           /                 \
               JSON saves / quests       schedules / routes
                                  |
                     optional explicit AI request
                          gs_backend.Client
                       /                    \
                text via Python 3/curl     image service
```

Задача следующей итерации: расширить выборы для полноценной ролевой истории, добавить динамические NPC-цели/события, диалоговое состояние и генерацию портретов с проверкой альфа-прозрачности и стилистики.
