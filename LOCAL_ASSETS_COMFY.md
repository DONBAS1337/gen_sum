# DON-GEN v0.7: реальные ассеты, ComfyUI и опциональная взрослая AU

## Что увидели в \`gen_assets\`

В твоём **приватном** репозитории \`DONBAS1337/gen_assets\` есть:

- \`maps/map_default.png\` — детализированная топографическая карта лагеря с берегом, домиками, сценой, столовой, библиотекой, клубами и спортплощадками. **Это основной вариант**.
- \`maps/map_bg.jpg\`, \`maps/7dl_bg.jpg\` — дополнительные альтернативные планы.
- \`maps/map_icon_*.png\` — готовые круглые/персонажные иконки \`mi\`, \`sl\`, \`dv\`, \`un\`, \`ul\`, \`el\`, \`sh\`, \`vi\`, \`zh\`, \`od\`, \`yu\` и другие.
- \`sprites/normal/mi\`, \`sprites/far/mi\`, \`sprites/close/mi\` — изображения Мику в разных выражениях, позах и деталях. Это не готовые универсальные RGBA-спрайты для случайного использования: части изображений могут быть слоями.
- Каталоги \`cg\`, \`misc\`, \`foods\`, \`transitions\` — отдельная библиотека CG и прочих ресурсов. Массового копирования/обработки этих материалов в данном обновлении **нет**.

Сами карты просмотрены через временную приватную GitHub Actions-визуализацию. После проверки вспомогательный workflow удалён из \`gen_assets\`. Для запуска игры **его не требуется**.

## Установка с импортом настоящей карты

Модификация остаётся в отдельной ветке \`feature/camp-sandbox-rpg\` репозитория \`gen_sum\`.

1. Скачай/клонируй \`gen_sum\` (ветка \`feature/camp-sandbox-rpg\`) и \`gen_assets\` (ветка \`main\`) на свой ПК. Для приватного \`gen_assets\` войди в GitHub через привычный Git/браузер.
2. **Закрой игру**.
3. Из каталога \`gen_sum\` запусти:

\`\`\`powershell
.\install.ps1 -GameDir "D:\SteamLibrary\steamapps\common\Everlasting Summer" -AssetsDir "D:\MyProjects\gen_assets"
\`\`\`

Можно указать непосредственно \`-AssetsDir "D:\MyProjects\gen_assets\maps"\`. Скрипт копирует **только карту и map_icon_*.png** в \`game/mods/don_gen/images/gen_assets\`, без больших CG, без токенов GitHub и без изменений исходного репозитория. Если \`-AssetsDir\` не указан, используются имеющиеся собственный атлас DON-GEN и старый дополнительный \`camp_map.png\`.

**Карта определяется автоматически**: при наличии \`images/gen_assets/map_default.png\` используется она и её специально расположенные активные точки (12 основных ориентиров). Кнопка **«ВСЕ 70 МЕСТ»** открывает список дополнительных зданий и домиков. При наведении подсвечивается значок места, а в панели показываются название и NPC. Рядом с точками персонажей появляются настоящие иконки \`map_icon_*.png\`, если установлены, иначе прежние пиктограммы/спрайты.

Ассеты \`gen_assets\` остаются приватными, **не загружаются в публичный \`gen_sum\`**. Не вставляй GitHub-токен в код игры.

## ComfyUI (твоя локальная GPU)

Путь \`127.0.0.1:8188\` используется непосредственно для штатного HTTP API ComfyUI. \`127.0.0.1:8189\` — отдельный локальный сервис предпросмотра/кэша Wayward, его API пока неизвестен. DON-GEN **не обращается к нему автоматически и не меняет его 3116 записей кэша**.

Поддержка работает по штатной схеме \`POST /prompt\` → \`GET /history/{prompt_id}\` → \`GET /view\` и только по localhost:8188. Она **не требует ChatGPT-входа** для фоновых/спрайтовых картинок. Для художественных **текстовых** сцен ChatGPT по-прежнему используется, если нажать AI-сцену.

### Что нужно один раз сделать в ComfyUI

1. Запусти твой ComfyUI с моделью \`anima_base_v1\` и открой свой **реально работающий workflow**. Anima Base v1 использует специальные узлы/текстовый энкодер Qwen и её нельзя автоматически заменить на произвольный SD1.5-workflow.
2. В поле **основного позитивного текста** вместо старого описания поставь маркер \`__DG_PROMPT__\`. Если workflow использует негативный промпт, можно поставить \`__DG_NEGATIVE__\`; для seed — \`__DG_SEED__\`. Оставь узел \`SaveImage\`, сохраняющий **PNG**.
3. Экспортируй **API-format JSON** (обычный UI JSON с \`nodes: []\` не подходит) и сохрани под именем \`comfy_workflow_api.json\` в папку \`Everlasting Summer\game\mods\don_gen\`. Можно использовать более конкретные файлы:
   - \`comfy_workflow_background_api.json\` — для генерации фоновых изображений;
   - \`comfy_workflow_sprite_api.json\` — для генерации PNG-спрайтов.
4. Для спрайтов подготовь отдельный workflow с корректным **альфа-каналом** и удалением фона (обычный вывод Anima часто непрозрачный). Без RGBA спрайт DON-GEN отвергнет, а сохранение не испортит.
5. В игре, в RPG-хабе, открой **«Художник: ...»** и выбери **«COMFYUI · 127.0.0.1:8188»**. Нажми обычную кнопку «Создать фон локации» или «Спрайт» у NPC.

Созданные PNG проходят валидацию и сохраняются в индивидуальном каталоге текущей RPG-смены \`_rpg/assets/<id>/\`; обычные PNG и сохранения других модов не меняются.

Если workflow возвращает ошибку, DON-GEN показывает ошибку и оставляет прежние файлы/сохранения. Проверить статус можно в ComfyUI на порту 8188 и \`Everlasting Summer\traceback.txt\`.

**Ограничение:** удалённо проверить API твоего собственного ComfyUI и конкретную конфигурацию \`anima_base_v1\` я не могу. Штатные API ComfyUI и офлайн-тесты адаптера проверены; сами картинки пока требуют игрового smoke-test.

## Взрослая альтернативная вселенная 18+ (opt-in)

- **По умолчанию выключена**. Включается при создании персонажа или в отдельном окне настроек текущей RPG-смены, только если возраст героя **18+** и выбран явный режим «Подтверждаю 18+».
- В этой альтернативной AU у допущенных NPC **явно взрослые версии**: Мику, Алиса, Лена, Славя, Женя, Шурик, Электроник, Ольга Дмитриевна и Виола. Их AU-возрасты заданы отдельной таблицей, а оригинальный канон **не подменяется**. Ульяна и Юля исключены из любого эротического взаимодействия — независимо от переключателя.
- Контекст LLM получает разрешение учитывать зрелую романтику и темы взрослых отношений **только по инициативе игрока**, при взаимном согласии. Режим не придумывает новые сюжетные последствия или награды и не гарантирует, что удалённая модель создаст любой запрошенный текст.
- Отключение не удаляет старую историю и не переписывает прошедшие сцены. Ограничения на допустимых персонажей применяются к гибридным и обычным свободным действиям, а также к отдельной AI-сцене NPC.

Это экспериментальная функция без гарантий работы всех Ren'Py-экранов до твоей проверки в Everlasting Summer 1.6 / Ren'Py 7.4.11.

## Тесты

Проверяются: архивная разметка карты, 70 доступных мест, проверки возраста и согласия, сохранение 18+ по отдельным сменам, исключение неподходящих NPC, защита сетевых запросов только к локальному ComfyUI, API workflow с заменой маркеров, ошибка невалидного workflow, симулированная очередь/получение PNG и прямой запуск генерации изображений без логина.
