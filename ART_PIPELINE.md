# DON-GEN v0.8 · Only backgrounds + cinematic CG

**Спрайты больше НЕ генерируются.** Игровые персонажи рисуются из оригинальной Everlasting Summer и доступных готовых PNG. Оставшаяся в старых сохранениях картинка спрайта читается для совместимости; кнопки генерации спрайтов, отправки в ComfyUI и требования к прозрачным слоям отсутствуют.

## Что происходит в игре

### Фоны (BG)
- Для **12 точно сопоставленных канонических мест** сразу показываем оригинальную сцену БЛ. Генерацию не запускаем и кнопку создания не показываем.
- Для остальных локаций (в том числе 31 домика) оригинальная игра не всегда имеет **соответствующий конкретному месту** фон. Пока картинка не создана, на экране может быть безопасная близкая по смыслу подстановка, а кнопка **«Сгенерировать отсутствующий фон»** позволяет создать оригинальный BG.
- Когда пользователь **сам** нажал кнопку генерации, полученный PNG сохраняется в индивидуальном кэше смены \`_rpg/assets/<id>/background_<place>.png\`. Последующие визиты используют этот файл без нового запроса.
- Переключатель настроек **«Приоритет: оригинальные / сгенерированные»** определяет, чем пользоваться, если доступны оба изображения. Генерация не вызывается автоматически при каждом перемещении.
- Есть один неустранимый без ручной разметки нюанс: generic fallback с фоном соседнего места не считается точным соответствием и не блокирует кнопку генерации.

### Полноэкранные иллюстрации (CG)
- Крупные сюжетные события, личные эпизоды NPC, события между персонажами, отдельные текстовые AI-сцены и гибридные эпизоды могут показывать кнопку **«Посмотреть / создать CG»**. Короткая незначительная реплика не требует изображения.
- Картинка привязана к **стабильному 40-символьному ID именно этого эпизода**, а не только к имени персонажа. Для ранее нарисованного CG выводится существующий PNG. При отсутствии CG сначала остаётся обычный текст, затем на отдельном экране предлагается **ручная генерация**. Не рисуется ничего просто при открытии диалога.
- CG после успешной генерации появляется в **«ГАЛЕРЕЯ CG · иллюстрации смены»**. Сцены разных смен не смешиваются; повторное открытие из галереи не вызывает ComfyUI.
- Сгенерированные CG хранятся как \`_rpg/assets/<id>/cg_<sha1>.png\`. Взрослые CG — отдельно \`cg18_<sha1>.png\`.
- Если уже есть **точно назначенный** готовый CG (см. следующий раздел), используется он. Нельзя надёжно считать произвольную картинку из большого каталога \`gen_assets/cg\` подходящей к любой случайно созданной текстовой сцене без явного сопоставления.

### Как подключить готовые CG из приватного \`gen_assets\`

Если хочешь избежать генерации для **конкретного сюжета**, положи в корень локального \`gen_assets\` файл \`cg_index.json\`:

\`\`\`json
{
  "0123456789abcdef0123456789abcdef01234567": "mods/don_gen/images/gen_assets/cg/mi_concert.png"
}
\`\`\`

Вместо примерного ID укажи **реальный ID**, показанный на экране отсутствующего CG. Рядом с индексом храни сам файл в \`gen_assets/cg/mi_concert.png\`. При установке с параметром \`-AssetsDir\` копируются **только файлы, перечисленные в индексе**, а не гигабайты CG. Если файла нет, игра предложит генерацию; молча подставлять несоответствующий CG она не будет.

### Взрослые CG (18+)

- Отдельный CG-тип \`cg18\` создаётся **не от одного факта включённого режима 18+**, а только при явно взрослой сцене и подтверждённой взрослой AU для героя 18+ и разрешённого персонажа.
- Юля и Ульяна исключены. Предварительные проверки делают запрос недоступным для их сценариев.
- Для \`cg18\` разрешена **только локальная ComfyUI**, облачный генератор исключён. Для обычного CG доступны ComfyUI и облачный генератор.
- Специальный \`comfy_workflow_cg18_api.json\` необязателен: при его отсутствии применяется обычный \`comfy_workflow_background_api.json\`, но с другим контролируемым промптом. Если результат не подходит художественно, можно подготовить отдельный workflow.
- В галерее CG18 не отображаются, если взрослый режим выключен.

## Подключение твоего Anima Base v1.0

Файл **\`comfy_workflow_background_api.json\`** из прошлого сообщения уже содержит \`__DG_PROMPT__\`, \`__DG_NEGATIVE__\`, \`SaveImage\` и аспект 16:9. Оставь его в:

\`\`\`text
Everlasting Summer\game\mods\don_gen\comfy_workflow_background_api.json
\`\`\`

Это **единственный обязательный workflow** для всех BG и обычных CG. Можно создать более специализированные \`comfy_workflow_cg_api.json\` и \`comfy_workflow_cg18_api.json\`; движок автоматически использует их, если найдёт.

**Текстовый seed не нужен.** DON-GEN сам подменяет **число** в поле \`KSampler.inputs.seed\` при каждой генерации, не изменяя исходный JSON. Параметры модели, разрешение 16:9, CFG, sampler и LoRA остаются как в твоём API workflow.

Схема запросов: \`POST http://127.0.0.1:8188/prompt\` → \`GET /history/<id>\` → \`GET /view\`. Wayward-сервис на 8189 остаётся нетронутым. Чтобы экономить токены: текстовые LLM-запросы делаются только для выбранных AI-сцен; графика работает локально.

**Проверки:** Python 2.7 grammar + тесты Python 3 для алгоритма ресурсов, идентификаторов сцен, кэша, защиты 18+, числового seed и отсутствия маршрута генерации спрайтов. **Сам Ren'Py 7.4.11 в твоей Steam-игре этим CI не запускался.** При любой ошибке пришли \`traceback.txt\`, при ошибке генерации — также вывод консоли ComfyUI.
