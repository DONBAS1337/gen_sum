# gen-7dl-vanilla

Экспериментальная ветка Generative Summer с выбором источника истории.

Сейчас работает:

- обычный vanilla-режим без изменений для старых историй;
- профили `7dl:mi_7dl`, `7dl:mi_dj`, `7dl:mi_cl`;
- автоматический поиск 7DL Complete Edition (`3266357374`) в той же Steam Workshop-библиотеке;
- безопасный текстовый индексатор `.rpy`: код 7DL не исполняется;
- релевантные сцены 7DL подмешиваются в prompt как справочный контекст;
- генерация фонов остаётся текущей рабочей реализацией GS.

Первый запуск 7DL-профиля строит локальный индекс в `saves/generative_summer/_source_cache/7dl_index.json`, поэтому первая генерация может стартовать дольше.

Следующие шаги: подключить приватный каталог фонов/звуков 7DL, затем отдельно составные спрайты и CG.
